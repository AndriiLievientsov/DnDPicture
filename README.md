# DnDPicture

Изображения для русской вёрстки D&D Essentials Kit в Homebrewery (проект «Ледяные драконы»).

| Папка | Книга |
|---|---|
| `doip/` | Дракон Ледяного Пика |
| `slw/` | Ярость Повелителя Бурь |
| `sdw/` | Пробуждение Спящего Дракона |
| `dc/` | Божественный Конфликт |
| `bg1/` | Врата Балдура. Часть I: Наследие Баала (каталог — в проекте, `1\v20 (4.0)\_рабочее\Каталог_артов.md`) |
| `bg2/` | Врата Балдура. Часть II: Тени Амна и Трон Баала (каталог — в проекте, `2\v21 (4.0)\_рабочее\Каталог_артов.md`) |
| `shared/` | используется в нескольких книгах |
| `_preview/` | миниатюры каждой папки с номерами каталога |

Полный каталог (источник, альтернативы, куда вставлена, статус): [CATALOG.md](CATALOG.md).
